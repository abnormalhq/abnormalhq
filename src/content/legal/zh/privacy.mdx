## 适用范围

本政策适用于 Abnormal（以下简称「我们」）运营的以下网站与服务：

- **官网**：abnormalhq.com，包括邮箱商店、订单与账户页、兑换开通页和使用教程（2026 年 11 月前位于 onboard.abnormalhq.com，现已跳转到官网）。
- **网页邮箱**：webmail.abnormalhq.com。
- **服务状态页**：console.abnormalhq.com/status。
- **已连接的应用**：工作区管理员把 Claude 或其他应用连接到管理系统控制台的 MCP 服务器（console.abnormalhq.com/api/mcp）时，该服务器及其 OAuth 登录（见「Claude 及其他已连接的应用」）。
- 通过上述服务开通的 @abnormalhq.com 及既有 @abnormal.bid 等邮箱，以及经 IMAP / SMTP 等协议的使用。
- 你通过我们公布的联系方式（邮箱、微信、Telegram 等）进行的咨询，以及双方另行确认的域名邮箱、团队邮箱或配置协助等服务。

你通过邮箱与第三方往来（例如收发邮件、用它注册其他网站）时，对方对信息的处理适用对方的隐私政策。

## 官网收集的信息

官网是静态页面，不设账号、不需要登录，也不使用统计脚本。你浏览官网时，我们不会主动收集你的个人信息。

- **咨询弹窗**：你在弹窗中选择的服务类型、使用时长和填写的需求，只在你的浏览器中整理成一段文字。官网不会把这些内容发送到我们的服务器，也不会保存。只有当你复制后发送给我们，或点击「通过邮件咨询」在你的邮件客户端里发送时，我们才会收到。
- **外观偏好**：你手动选择浅色或深色模式时，选择会保存在浏览器的本地存储（`abnormal-theme`）中，仅用于记住外观；商店与开通页使用同一项偏好。它不会发送给我们，选择「跟随系统」即可清除。
- **地址查询**：网站提供「查一查想要的地址」时，你输入的用户名和域名只会发到我们的服务器，用来回答这个地址是否可用；查询不与你的身份关联，请求也不带 Cookie。你选定的地址会保存在浏览器当前标签页的会话存储（`abnormal-address`）里，方便商店和开通邮箱的表单替你填好；它不会从那里发给我们，关闭标签页或选择「不用这个地址」后即清除。
- **语言偏好**：你点击页头的语言切换时，浏览器会保存一个只记录「中文」或「英文」的 Cookie（`abnormal_lang`，有效期一年，作用于 abnormalhq.com 及其子域名），官网、商店与开通页、网页邮箱据此显示同一种语言。没有这个 Cookie 时按浏览器语言显示。它不含任何身份信息，也不用于统计；在网页邮箱的语言菜单选择「跟随浏览器」或清除浏览器 Cookie 即可删除。
- **托管服务**：官网托管在 Cloudflare，网页字体随网站一同托管，不向第三方字体服务请求。服务商可能按其政策记录 IP 地址、浏览器类型等访问日志，这些数据由服务商处理，我们无法访问。详见 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)。

## 购买与开通时处理的信息

在商店购买、管理订单或用兑换码开通邮箱时，我们会处理以下信息：

- **订单信息**：所选套餐、价格与优惠、订单号、支付方式、支付状态、支付渠道返回的交易号、金额与时间，以及订单对应的兑换码与续费记录。
- **优惠码**：你在商店输入的优惠码会发到我们的服务器，用来核对并计算订单价格，并随订单一起记录。使用了优惠码的订单，浏览器还会把优惠码和使用前的套餐价格保存在当前标签页的会话存储（`abnormal-coupon`）里，只用于在订单页显示优惠了多少；它不会从那里发给我们，关闭标签页后即清除。
- **联系邮箱**：下单或续费时你可选填的邮箱，用于发送到期与续费提醒，并在你登录商店账户时找回对应订单。
- **商店账户**：你用于注册和登录「我的账户」的邮箱，以及你设置的账户密码。密码只以不可逆的哈希形式保存，我们看不到原文。注册时我们会向该邮箱发送确认链接；你也可以用发到该邮箱的一次性登录链接登录（有效期 15 分钟），并在登录后重设账户密码。
- **用 Google 登录**：如果你选择「使用 Google 登录」，你会在 Google 的页面上选择账户并同意，Google 随后告诉我们你的 Google 账户标识与经 Google 验证的邮箱地址；我们不会收到你的 Google 密码，也不会读取通讯录等其它资料。我们用这些信息登录你关联的商店账户；对 Gmail 和 Google Workspace 邮箱，也会登录或开通与该邮箱相同的商店账户并自动关联，其它邮箱需要你登录后在「我的账户」中关联。我们保存关联关系，以便你下次直接登录；你可以在「我的账户」中解除关联。Google 对这一过程的处理适用 [Google 隐私权政策](https://policies.google.com/privacy)。
- **购买会话 Cookie**：下单时浏览器会保存一个随机标识（`mailhq_shop`，HttpOnly），用来在同一浏览器里领取兑换码、查看订单，有效期一年，每次下单续期。我们的数据库只保存它的摘要，订单号本身不能用来领取兑换码。
- **支付信息**：Linux DO Credit 支付在 Linux DO Credit 完成；银行卡支付在 Stripe 完成，卡号、有效期与安全码由 Stripe 处理，我们不接触也不保存。我们只接收支付结果、交易号、金额，以及银行卡订阅所需的 Stripe 客户与订阅编号。
- **开通信息**：你输入的兑换码、选择的域名与用户名、为邮箱设置的密码。若你填写了「接收邮箱」，我们会把新邮箱的地址、密码与服务器地址发到该地址一份。
- **购买者对邮箱的管理**：用某个订单的兑换码开通的邮箱，归该订单的购买者在「我的账户」中管理，包括购买者把兑换码转送给你、由你开通的邮箱。购买者可以看到这些邮箱的地址、状态与用量，并可以重设邮箱密码、停用或删除邮箱；这些操作会记入管理系统的操作日志。
- **自有域名**：如果你的套餐包含自有域名，并且你在「我的账户」中接入了自己的域名，我们会把域名与你的商店账户一并保存，同时保存发给你用于验证的所有权记录、域名通过验证的时间及其所处的状态（等待验证、审核中、已开通或已暂停）。为了核对记录，我们会在公共 DNS 中查询这些记录；我们不会修改你的 DNS。域名以及每一步操作（登记、验证、审核通过、暂停、移除）和操作人会记入管理系统的操作日志；管理员在审核或管理域名时，可以看到域名、你的账户邮箱和域名下的邮箱。
- **安全信息**：请求来源 IP 地址与浏览器信息，用于限制请求频率、阻止猜测兑换码等滥用行为。
- **人机验证**：开通页、商店登录、网页邮箱登录与管理系统登录可能经过 Cloudflare Turnstile 人机验证。它会读取浏览器发出的信号（如浏览器特征和页面交互情况）来区分真人与自动程序，多数时候无需操作；我们只收到「通过 / 未通过」的结果。见 [Cloudflare Turnstile 隐私附录](https://www.cloudflare.com/turnstile-privacy-policy/)。

## 使用邮箱时处理的信息

邮箱开通后，提供收发与存储服务必然会处理以下信息：

- **邮件与邮箱数据**：你收发的邮件（发件人、收件人、主题、正文、附件）、文件夹与已读、星标等标记。它们保存在我们自建的 Stalwart 邮件服务器上，用于为你投递、存储和展示邮件。我们不会分析邮件内容用于广告，也不会出售。
- **邮件收发记录**：投递时间、收发双方地址、投递结果、垃圾邮件判定等服务器日志，用于投递、反垃圾和排查故障。
- **账号信息**：邮箱地址、所属套餐、容量与每日发信上限、有效期与订阅状态。邮箱密码以加密形式保存在管理系统中，用于网页邮箱登录与邮箱管理。
- **网页邮箱**：登录后浏览器会保存会话 Cookie，用来保持登录和同时登录多个邮箱；你设置的自动转发保存在服务器上，外观偏好只保存在浏览器里。
- **AI 功能**：以下功能会把相关内容经 Cloudflare AI Gateway 发送给第三方大模型服务商（目前为 DeepSeek）生成结果：
  - **AI 写作**（起草、改写、润色、翻译）：你写的内容或选中的文字、你的指令、主题、收件人，以及回复或转发时引用的原邮件。
  - **对话摘要与建议回复**：在你发起时，发送该对话中邮件的发件人、收件人、时间、主题和正文。
  - **自然语言搜索**：只发送你输入的那句话和当天日期，不发送邮件内容。
  - **跟进任务**：任务说明，以及任务运行时搜索和读取到的本邮箱邮件。任务创建后会按计划或在收到相关邮件时自动运行，直到完成或被取消，并可能按所选的发送方式自动发信。任务需要联网时，搜索词和要读取的网页地址会发送给 Tavily。
  - **工单 AI 助手**：开启时，你提交的工单会先由它处理，发送工单文字以及邮箱地址、状态、创建时间、容量用量和邮件数量，以及我们帮助资料里与你的问题最相关的几段。

  除上述情形外，邮件内容不会发送给大模型服务商。

- **按意思查找**：为了替工单 AI 助手挑出相关的帮助资料，工单主题和你最新的一条消息会发送给 Cloudflare Workers AI，转换成一组数字（向量）后用来比对，不会被保留。管理系统另有「语义搜索」功能，开启后会把邮件的主题、收发件人和正文开头交给 Cloudflare Workers AI 生成向量，存放在 Cloudflare Vectorize，供管理员按意思查找邮件；这项功能目前没有开启，开启前我们会先更新本政策。Workers AI 不保留也不用这些内容训练模型，调用也不经过会记录日志的 AI Gateway。

- **工单与求助**：你在网页邮箱提交的工单、往来消息与附带信息。

**管理员访问**：为维护服务，我们的管理系统在技术上可以查看邮箱内容。我们只在以下情形访问：排查你的邮箱或系统故障、处理你本人提出的求助、处理滥用举报或安全事件、依法配合有权机关。查看、移动、删除邮件与发信等操作会记录在管理系统的操作日志中。

**管理员使用 AI 功能**：有发信权限的管理员在管理系统中处理你的邮箱时，也可以使用 AI 写作、对话摘要、建议回复和自然语言搜索，或通过管理系统和管理 API 为邮箱创建跟进任务，相关内容同样会发送给大模型服务商。这些使用同样只限于上一段列出的情形。

## 咨询与定制服务时处理的信息

你主动联系我们，或使用双方另行确认的定制服务时，我们可能处理：

- **联系方式**：你用于联系我们的邮箱地址、微信号或 Telegram 账号，以及沟通中提供的称呼。
- **需求信息**：需要的服务、邮箱数量、服务期限，以及域名、设备与邮件客户端等补充说明。
- **开通与配置所需信息**：根据确认的方案，可能需要你提供域名、指定的邮箱地址等必要信息。我们会在开始前说明需要哪些信息及用途。
- **沟通记录**：咨询、确认方案和售后过程中的往来消息。

## Claude 及其他已连接的应用

管理系统控制台（console.abnormalhq.com）中某个工作区的管理员，可以把 Claude（即「Claude 连接器」）或其他支持 Model Context Protocol（MCP）的应用，连接到控制台的 MCP 服务器 console.abnormalhq.com/api/mcp。应用通过 OAuth 2.0 登录：管理员登录控制台，在授权页上选择应用可以读取或修改哪些内容，然后批准。只有管理员可以这样做。如何连接、应用能做什么和不能做什么，见 [Claude 连接器页面](/zh/claude/)。

- **我们收集的信息**：每个连接的应用名称、客户端 ID 和返回地址、授予的权限、所属工作区和管理员账号，以及连接的创建时间和最后使用时间。应用使用的令牌只以 SHA-256 哈希形式保存。每次请求，我们只收到应用为完成这项操作而发送的内容，例如邮箱地址、新的容量或邮件追踪的查询条件；我们从不接收你与 Claude 或其他应用之间的对话。
- **使用与保存方式**：用于按授予的权限和管理员当前的角色检查每个请求，并通过管理 API 执行，检查与限制都与使用 API 密钥的请求相同。连接与工作区的其他设置一起保存在我们的数据库中。经连接做出的每一项修改，以及每一次邮件追踪查询及其查询条件，都会记入工作区的操作日志，并注明是哪个连接（`oauth:` 加上连接的 ID）；每个请求也会像 API 密钥的请求一样计入 API 调用统计（路径、状态和耗时，不含请求内容）。连接只能触及管理 API 提供的内容：它不能读取邮箱中的邮件，只有在管理员授予跟进任务权限时，才能看到跟进任务中保存的内容（任务说明、所跟进对话的主题和发件人、收到的邮件的开头，以及任务写出的邮件）。
- **共享**：除「信息的共享与服务商」中列出的服务商外，我们不会把连接信息提供给任何人。应用发给我们什么、如何处理收到的结果，由应用的提供方负责：对于 Claude，Anthropic 对你的对话的处理适用 [Anthropic 隐私政策](https://www.anthropic.com/legal/privacy)；对于其他应用，适用其提供方的政策。
- **保存期限**：访问令牌 1 小时后过期，刷新令牌 30 天后过期，每次刷新都会换发新的刷新令牌；连续 30 天未使用的连接会过期。管理员在应用中断开连接、在「账号设置 → 已连接的应用」中撤销（管理员还可以在「设置 → API 密钥 → 已连接的应用」中撤销工作区的任何连接）、修改控制台密码或登录邮箱，或不再是该工作区的管理员或成员时，连接随即结束。经连接产生的记录作为工作区操作日志的一部分保存（见「信息保存期限」）；API 调用统计由 Cloudflare 的统计服务保存约三个月。你可以随时要求我们删除已结束连接的记录。
- **联系我们**：关于已连接的应用或本节内容的任何问题，请通过「联系我们」中的方式与我们联系。

## 我们如何使用这些信息

- 确认支付、发放兑换码、开通邮箱，并为你投递、存储邮件。
- 发送服务所必需的邮件：商店注册确认邮件、登录链接与重设密码邮件、账户密码设置或修改提醒、关联 Google 登录的提醒、开通后的账号信息（仅当你填写了接收邮箱）、到期与续费提醒、订阅扣款与状态变化。
- 处理续费、到期、停用与恢复，处理退款与争议。
- 提供使用支持，回复工单与咨询。
- 提供上文所述的 AI 功能：生成写作内容、摘要、回复建议和搜索条件，运行跟进任务，先行处理工单。
- 保障安全：人机验证、限制请求频率、识别并处置垃圾邮件、钓鱼、盗号与其他滥用行为。
- 记账，以及履行法律法规要求的义务。

我们不会将你的信息用于与服务无关的营销，也不会在未经你同意的情况下向你发送推广信息。

## 信息的共享与服务商

我们不出售、不出租你的个人信息。为提供服务，以下服务商会在各自职责范围内处理必要的信息：

- **Cloudflare**：托管官网，运行商店、开通页、网页邮箱与管理系统，提供网络传输、运行日志、AI Gateway、人机验证（Turnstile）和按意思查找（Workers AI 与 Vectorize），在 R2 中保存工单里的截图，并运行跟进任务。
- **数据库服务商**：保存账号、订单、兑换码、工单文字、跟进任务记录与设置等数据（目前为 PlanetScale）。
- **邮件服务器的云主机服务商**：承载我们自建的邮件服务器与邮件数据。
- **Linux DO Credit** 与 **Stripe**：处理你选择的支付方式，其收集的信息适用各自的隐私政策。
- **大模型服务商**（目前为 DeepSeek）：仅在使用上文所述的 AI 功能时，接收生成结果所需的内容。
- **Tavily**：仅在跟进任务联网时，接收搜索词和要读取的网页地址。

此外，你发出的邮件会按邮件协议投递到收件人的邮件服务器；依据法律法规、监管机关或司法程序的要求，我们可能提供必要的信息。

## 信息保存期限

- **邮件与邮箱**：服务有效期内一直保存，你可以自行删除邮件。到期后有 7 天宽限期，期间照常使用；宽限期满邮箱停用，邮件与数据继续保留 30 天，期间仍可续费恢复；保留期满进入待回收状态，经管理员确认后删除邮箱及其中的邮件。
- **工单与跟进任务记录**：工单往来、AI 助手的草稿，以及跟进任务的说明、往来消息和运行记录（可能包含读取到的邮件片段）保存在数据库中。目前它们不会随邮箱删除而自动清除，你可以随时要求我们删除（见「你的权利」）。
- **订单与支付记录**：为处理售后、续费与争议，自服务结束之日起保留最长 12 个月，之后删除或匿名化；法律法规要求更长保存期限的除外。
- **登录与会话**：商店注册确认链接、登录链接与重设密码链接 15 分钟内有效；商店账户的登录状态保存 30 天，修改账户密码后其它浏览器上的登录随即失效；购买会话 Cookie 有效期一年；网页邮箱会话在你退出登录或到期后失效。
- **自有域名**：在所有权验证通过之前放弃的域名，会立即从你的账户中删除。验证通过的域名在接入期间一直保存。包含自有域名的最后一个套餐到期后，域名与其下的邮箱一样经历 7 天宽限期和 30 天保留期；此后不会自动删除任何内容，域名在管理员移除后删除，你可以随时要求我们移除。操作日志中的相关记录按下文所述保存。
- **运行与访问日志**：按托管服务商的保留期限自动删除；管理系统的操作日志用于安全审计，随服务长期保存。
- **未继续使用服务的咨询**：相关沟通记录在咨询结束后 3 个月内删除。
- 你也可以随时要求我们提前删除（见「你的权利」），但处理进行中的订单、争议或法律要求保存的信息除外。

## 信息安全

- 各站点全程使用 HTTPS；支付凭据、商户密钥等敏感配置加密保存；开通结果中的密码只显示一次。
- 兑换、登录与支付接口按 IP 限制频率，商店账户的密码尝试还按账户限制次数，异常的兑换码猜测会被锁定；管理系统按角色授权，敏感操作记入操作日志。
- 除了你在开通页、商店账户、网页邮箱登录页或修改密码时自己输入，我们不会通过邮件、聊天等任何渠道索要你的密码、验证码或支付卡信息。如有人以 Abnormal 的名义索要，请勿提供，并通过本页「联系我们」中的邮箱向我们核实。
- 请妥善保管兑换码、邮箱密码、商店账户密码与商店登录链接：任何持有兑换码的人都可以用它开通邮箱，能登录你商店账户的人可以管理你名下的邮箱。
- 任何互联网传输都存在一定风险。如发现账号异常，请尽快修改密码并联系我们。

## 你的权利

你可以随时通过「联系我们」中的方式：

- 查询我们持有的关于你的信息；
- 更正不准确或不完整的信息；
- 要求删除邮箱、订单或账户信息，或撤回同意（可能导致服务无法继续）；
- 通过 IMAP 等邮件客户端自行导出你的邮件；
- 对本政策或我们处理信息的方式提出疑问或投诉。

我们会在核实你的身份后处理，一般不超过 15 个工作日答复。为核实身份，我们可能要求你从相应邮箱发信，或提供订单号等信息。

## 未成年人

我们的服务面向成年人。如果你未满 18 周岁，请在监护人同意并陪同下使用本网站和服务。如我们发现未经监护人同意收集了未成年人的信息，会尽快删除。

## 信息的跨境传输

我们使用的托管、数据库、邮件服务器、支付与大模型服务商可能位于中国大陆以外的地区，提供服务所必需的信息会因此传输并保存在境外。我们只传输服务所必需的信息，并按本政策保护这些信息。

本政策可能随服务内容或法律要求而更新。更新后我们会在本页面发布新版本，并更新页首的「最后更新」日期；重大变更会在本页面以显著方式提示。你继续使用本网站或服务，即表示接受更新后的政策。
